# Phase 12: Voiceover visuals

**Feature:** Feature 1 output, uses Feature 4
**Depends on:** phases 06 and 07

## Goal

The `voiceover` kind gets real visuals: each script block is matched to a stock clip or a generated image.

## Build

- Stock adapter (Pexels / Pixabay) and image-model adapter in `packages/providers`.
- Per-block visual query generated by the LLM; pick the best stock clip, else generate an image, else fall back to the styled background.
- Selected media is ingested through `asset.ingest` so it gets variants and a licence record.
- Update the `voiceover` generator to place one `MediaClip` per block with Ken Burns on still images.
- UI to swap the visual of a block before generating.

## Data

- No new tables; assets get `source` values `stock` and `ai_image`.

## Done when

- [ ] A five-block script produces five matching visuals timed to their blocks.
- [ ] With both providers disabled the video still completes on the styled background.

## Not in this phase

- Generated video footage (phase 18).
