# design-primitives.md — the forked `ui/` layer

> SOURCE OF TRUTH KEYWORDS: PRIMITIVES_ARE_FORKED, DO_NOT_REGENERATE,
> design-primitives, shadcn add, overlay-pop, tactile-\*, focus-ring,
> --ease-settle
>
> Scope: `src/components/ui/**`. The visual rules live in `design.md` and
> `design-buttons.md`; this doc is about the **files**, and what happens to
> them when the generator is re-run.

---

## 1. The rule

**`npx shadcn add <component>` overwrites `src/components/ui/<component>.tsx`
without asking.** Roughly **22 of the 31** primitives in that directory have
been deliberately modified, so for most of them that command is not an
install — it is a silent revert of work that is not recorded anywhere else.

This is not a list of exceptions to be careful about. The directory is a
**fork**. Treat `shadcn add` the way you would treat `git checkout --` on a
file you have not read.

### What to do instead

| Situation                                        | Do this                                                                                                                     |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Primitive already exists here                    | Edit it in place. Never regenerate.                                                                                         |
| Adding a primitive that does not exist yet       | Generate it into a scratch path, read it, port it in by hand, then apply §3 before using it.                                |
| You need the upstream version to compare against | `npx shadcn add <x>` into a throwaway directory outside `src/`, diff, delete. Never let it write into `src/components/ui/`. |
| You regenerated by accident                      | §4.                                                                                                                         |

## 3. What any primitive in this directory must adopt

A newly ported primitive is not finished until it speaks the same language as
its neighbours. This is the checklist, and it is also why the generator's
output is never correct here as-is.

1. **Tokens, never literals.** No hex, no `text-white`, no forced `dark`.
   `bg-card`, `border-border`, `text-muted-foreground`. (CLAUDE.md §7.)
2. **Surfaces** come from the `tactile-*` layer in `globals.css` — one border
   per surface, light from above. See `design-buttons.md` §1.
3. **Focus** is `focus-ring` (or `focus-ring-inset`), never a bespoke
   `ring-*`.
4. **Motion** names its properties and its curve: `transition-[a,b]`,
   `--ease-settle`, `motion-reduce:transition-none`. Never `transition-all`,
   never a bare `transition`, never `ease-linear` on something that starts and
   stops.
5. **Anchored overlays** (menus, popovers, selects, tooltips) take
   `overlay-pop` and `origin-(--transform-origin)` — transitions, not
   `animate-in` keyframes, so a reopen mid-close retargets instead of
   restarting. Modals are excluded: they centre with the `translate` property,
   which `overlay-pop` would overwrite.
6. **Press** is `active:translate-y-px`, size-independent, matching `Button`.
7. **Hover motion** is gated. Tailwind's `hover:` and `group-hover:` compile
   inside `@media (hover: hover)` (verified on Tailwind 4.3); a hand-written
   hover rule must state the query itself.

## 4. If a primitive was regenerated

1. `git diff src/components/ui/<file>.tsx` — the customisations appear as
   deletions. The generator's output is the `+` side.
2. Restore from the last good commit rather than re-deriving:
   `git show <ref>:src/components/ui/<file>.tsx`.
3. If upstream changes were genuinely wanted, port them onto the restored file
   by hand and re-apply §3.
4. Update this doc if what diverges has changed.

---

## 5. Keeping this doc true

CLAUDE.md §7 already requires that a UI change which the design docs do not
describe updates the doc in the same change. For this file that means: when
you customise a primitive that §2 does not list, add the row and the grep
keyword. A list that has silently gone stale is worse than no list, because the
next person trusts it and regenerates.
